← Mehk3y IP 情报 API

一个接口，判断任意 IP 的地理位置、代理/VPN/数据中心属性、0–100 信任评分，以及登录 Claude / AI 服务的风控风险等级。

同样的引擎已在 /ip 检测页对外服务。适合机场线路体检、账号风控、跨境业务的 IP 质量筛查。

快速开始

GEThttps://mehk3y.com/api/v1/check?ip=8.8.8.8
# 鉴权: 请求头 x-api-key 传入你的 key
curl "https://mehk3y.com/api/v1/check?ip=8.8.8.8" \
     -H "x-api-key: mk_你的key"

不带 ip 参数时，检测调用方自身的出口 IP。也支持 ?key= 查询参数鉴权。

响应字段

字段类型说明
trustScore0–100综合信任评分。越高越干净（受限地区强制 0）
trustTierstring极度纯净 / 纯净 / 良好 / 中性 / 可疑
claudeRisklow/medium/high登录 Claude / AI 的风控风险等级
restrictedRegionstring·null命中受限地区时返回地区名（如 中国大陆）
proxy / isVPN / isTORbool代理 / VPN / Tor 识别
isHostingbool是否数据中心 / 机房 IP
risk0–100上游风险分（proxycheck）
country / countryCode / city / regionstring地理定位
asn / isp / orgstring自治域号 / 运营商 / 组织
hasAbusebool是否有滥用记录（风险≥66）
