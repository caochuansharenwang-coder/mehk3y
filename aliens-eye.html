AI-OSINT Username Scanner

Aliens Eye

一个 Python 命令行 OSINT 工具，用 ML + 启发式规则在 800+ 平台上检查用户名，支持代理/Tor、结果导出、关联分析、域名检查、Watch 模式和 MCP server。

快速使用

这些命令来自原仓库 README。扫描第三方站点前，先确认你有合法用途，并遵守目标站点条款。

pip install aliens-eye
aliens_eye username --profile quick --no-nsfw
aliens_eye username --site github,reddit,gitlab --format all --output results
aliens_eye username --correlate --domains
aliens_eye serve

本页包含

已本地化 logo、示例图、站点映射 JSON 和示例训练 CSV。Python 包源码不在静态页运行；真正扫描仍应在本机或服务器 CLI 中执行。

ML + 启发式检测

把 HTTP 状态、DOM 结构、关键词、OpenGraph、JSON-LD、响应时长等信号混合评分，减少只看状态码的误判。

调查报告导出

支持 JSON、CSV、HTML、Markdown、PDF、GEXF、Mermaid、Maltego CSV 等输出，方便归档或继续分析。

高级扫描模式

支持用户名变体、站点过滤、排除 NSFW、代理/Tor、断点续扫、定时 Watch 和 webhook 通知。

关联分析

可按头像哈希、简介、共享链接和显示名，把多个站点命中聚成“可能同一人”的线索组。

MCP Server

通过 aliens_eye serve 暴露扫描能力给支持 MCP 的 LLM agent，适合自动化调查工作流。

可训练模型

可以采集正负样本、人工标注不确定结果，并重新训练/导出模型 JSON。

检测流程

1
加载站点读取 sites.json，合并 sites.d 自定义平台。
2
请求页面并发访问平台 URL，支持代理、Tor、重试和限速。
3
提取特征解析 HTML、meta、DOM、结构化数据和页面指纹。
4
混合判断ML 模型与启发式规则共同给出 Found / Maybe / Not Found。
5
导出报告生成 JSON、CSV、HTML、Markdown 或图谱文件。
