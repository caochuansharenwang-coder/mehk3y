工具：解析 eSIM 激活码

把运营商给你的 LPA: 开头的字符串粘贴进来，自动拆出 SM-DP+ 服务器、Matching ID 和确认码 —— 在 OpenEUICC 里手动添加 eSIM 时，三个字段要分别填。

OpenEUICC · 第 1 步：选对版本

OpenEUICC 是开源的 Android eSIM 管理工具，让你脱离运营商 app 自由管理 eSIM profile。项目其实有两个变种 —— 选错了根本装不上。先看你的需求：

第 2 步（普通用户）：EasyEUICC + 外置 eSIM 卡

  1. 买一张外置 eSIM 卡 推荐 eSTK.me（香港产，与 OpenEUICC 同一团队，原生兼容）。其他选择见下方"兼容硬件"清单。
  2. 插入到手机的实体 SIM 卡槽 外置 eSIM 卡和普通 SIM 卡一个尺寸，从 SIM 卡槽插进去。某些卡支持配 USB 读卡器使用。
  3. 下载 EasyEUICC APK 从下方"下载"区的 gitea.angry.im 链接下载，或从 GitHub Release 页下载。
    注意：不要去 Google Play 找，那里没有官方版本。
  4. 安装 APK 第一次安装会提示"未知来源"，需要在系统设置里允许。Android 8 以上要单独授予浏览器或文件管理器的安装权限。
  5. 打开 EasyEUICC，授予 SIM 权限 app 启动后会自动检测到外置 eSIM 卡。如果没检测到，把卡拔出来重插一次。
  6. 添加 eSIM Profile（推荐方式：扫码） 点 app 里的 + → "Scan QR" → 对准运营商提供的 eSIM 二维码。
  7. 添加 eSIM Profile（备用方式：手动填） 如果你只有 LPA: 字符串没二维码，先用本页顶部的解析工具拆出三个字段，然后在 app 里点 + → "Manual" → 分别填入 SM-DP+ 服务器、Matching ID、Confirmation Code。
  8. 启用 Profile 下载完成后，长按或点击 profile → "Enable"。手机会重新注册到该运营商网络，几秒后就能用。

第 2 步（高级用户）：OpenEUICC + 手机内置 eSIM

⚠️ 风险提示： 这条路涉及 root / 解锁 bootloader / 刷 Magisk 模块，操作不当可能变砖或导致 eSIM 丢失。继续前请确认你能接受这个风险。
  1. 确认设备已 root（Magisk）或运行支持 OpenEUICC 的自定义 ROM 例如 LineageOS、PixelOS 等部分 ROM 已内置 OpenEUICC。如未内置，则需要 Magisk root。
  2. 从 CI 下载 OpenEUICC Magisk 模块 官方没有正式 release，仅 CI debug 包。地址：gitea.angry.im/PeterCxy/OpenEUICC/actions → 选最新一次 build → 下载 Magisk 模块 zip。
  3. 在 Magisk 中刷入模块 Magisk app → 模块 → 从存储安装 → 选择刚下载的 zip → 重启。
  4. 重启后打开 OpenEUICC 会出现在 app 抽屉里。打开即可看到手机内置 eSIM 芯片。
  5. 添加 / 切换 / 删除 Profile 操作流程同 EasyEUICC（扫码或手动填三字段）。区别是这里管理的是手机内置 eSIM，不需要插外置卡。

giffgaff 英国电话卡

gg
giffgaff 是英国 O2 网络的 MVNO，号码长期保留、按需充值、零月租。先讲国内 0 成本开 eSIM，再附上日常使用速查。

0 成本开 giffgaff eSIM（安卓模拟器）

为什么这样开

国行 iPhone 不支持原生 eSIM，实体卡又贵又慢。

用电脑里的 安卓模拟器 骗过 giffgaff App 拿到 eSIM 激活码，再装到任何支持 eSIM 的设备 / 转接卡 / 9esim 下发方案上。

模拟器只是开卡工具，不是最终使用设备。

准备

• Windows 电脑（成功率最高，排错更容易）

• giffgaff 账号 + 可用支付方式

• 稳定海外网络（建议全局英国节点，仅浏览器代理不够）

• 工具包：MuMu 模拟器、Magisk、LSPosed、HookEuicc、Via 浏览器、giffgaff App

⚠️ 涉及 Root + Hook，不要在模拟器里保存主力账号、长期银行卡或重要隐私。
  1. 装 MuMu 模拟器，新建一台安卓设备。创建时务必同时开启"可写系统磁盘" + "Root 权限" —— 这是地基，没做好后面全废。
  2. 共享文件夹把工具包传进模拟器。
  3. 装 Magisk（面具）→ 选"直接安装到系统" → 重启。首次弹 Root 授权选"永久记住 / 授予"。
  4. Magisk → 模块 → 从本地安装 LSPosed → 重启。看不到通知栏入口？直接安装包里的 manager.apk。
  5. 装 HookEuicc → 打开 LSPosed → 启用模块 → 作用域勾选 giffgaff → 重启。
  6. 装 Via 浏览器（设为默认，登录跳转更稳）+ giffgaff App。
  7. 打开 giffgaff App → 进入 eSIM 页面，不再提示"设备不支持 eSIM"即通关。
  8. 正常流程购买 / 充值 eSIM → 拿到激活码。
  9. 激活码若被工具提示格式错误，前面补 LPA:，其余不要改：
    1$server$code → LPA:1$server$code提示：补好之后可以直接粘到本页顶部的激活码解析工具验证字段是否齐全。
  10. 用 9esim 下发：必须全局英国节点，模拟器和下发工具走同一网络环境。
卡住了？按依赖链回查

Magisk 装不上Step 1：Root + 可写系统盘没开。

付款失败多半不是 Hook 问题 —— 查银行卡 / 地址 / 风控 / 网络。

📌 报错从上往下排，不要从最后一步乱试。跳步骤是这类教程最大的坑。
拿到激活码之后

eSIM 不是只能用在模拟器里。激活码可装到：

• 国际版 iPhone / 安卓（原生支持 eSIM）

• eSIM 转接卡（5ber、esim.me、eSTK.me 等 —— 看上面的兼容硬件清单）

• 9esim 等下发方案

国行 iPhone 仍不能原生添加 eSIM，必须走转接卡或下发方案。

giffgaff 日常使用速查

1查询余额

发短信 INFO 到 85075（最快、最稳）。

或使用 giffgaff App / 官网登录查看。

2发不了短信？

必须加完整国际区号，例如：+86xxxxxxxxxxx。

对方如果是国内号码且未开国际漫游，也收不到。

3收不到验证码？

用英国住宅 IP（VPN 选 UK 服务器）成功率最高。

苹果手机：激活时先关 iMessage 和 FaceTime，否则验证码可能被苹果服务器拦截。

4保号防过期（最重要）

每 180 天 至少消费一次（发条短信就行，成本极低）。

在中国时务必关闭数据漫游，只发短信保号，避免巨额扣费。

⚠️ 数据漫游忘关 → 几十英镑一夜烧光，是 giffgaff 用户最常踩的坑。
5补卡 & 号码保留

实体卡坏了或丢了可免费补卡，号码不变。

已有实体卡的，可在 giffgaff App 内直接转 eSIM。

6英国 / 欧盟旅行

英国本地：零漫游，正常使用 Goodybag。

欧盟：Goodybag 套餐最多 5GB 公平使用上限，超出后 10p/MB。

  • 充值：支持 Visa / Master，部分渠道可用支付宝 / 微信。

常见问题

能直接在这个网页里下载 / 切换 eSIM 吗？OpenEUICC

不能。 浏览器没有访问 SIM 卡硬件的权限，OpenEUICC 必须以 Android 原生 app 形式运行。本页只能帮你解析激活码和看教程，真正的 profile 下载/切换要在 EasyEUICC / OpenEUICC app 里完成。

iPhone 用户能用 OpenEUICC 吗？OpenEUICC

不能。 OpenEUICC 是 Android 专属。iPhone 的 eSIM 由 iOS 系统封闭管理，第三方工具无法接入。如果你想在 iPhone 上用外置 eSIM 卡，eSTK.me Plus / Max 提供独立 RLPA Bootstrap 服务，可以不依赖 Android 设备直接激活。

EasyEUICC 不支持我的外置 eSIM 卡？OpenEUICC

EasyEUICC（非特权版）需要外置卡的 ARA-M 字段包含 2A2FA878BC7C3354C2CF82935A5945A3EDAE4AFA。eSTK.me 全系都包含；其他厂商的卡如果没包含，要么你联系厂商更新，要么改用 USB 读卡器（USB 路径无 ARA-M 限制），要么换装 OpenEUICC 特权版。

eSIM 激活后能转移到别的卡吗？OpenEUICC

这取决于运营商。SGP.22 标准支持 profile 转移，但大多数消费级运营商默认禁用。OpenEUICC 本身能完成转移操作，但前提是运营商在签发 profile 时允许。如果不允许，转移会被服务端拒绝。

用 EasyEUICC 安装运营商激活码失败？OpenEUICC

常见原因：
① SM-DP+ 服务器拒绝连接 —— 部分运营商绑定了特定 EID 范围，外置卡的 EID 不在白名单里就会被拒。
② Matching ID 已使用 —— 激活码是一次性的，下载过一次再下要联系运营商重发。
③ Confirmation Code 错误 —— 用本页顶部的解析工具确认你是不是漏填或填错了第四个字段。

OpenEUICC 安全吗？会盗我数据吗？OpenEUICC

项目是 GPL-3.0 开源、社区维护、源码可审计。它直接和你的 eUICC 芯片用 SGP.22 标准协议通信，profile 数据走运营商的 SM-DP+ 服务器（端到端加密），OpenEUICC 本身只做 LPA 中转，不上传任何数据到第三方。

为什么 OpenEUICC 没正式 release？OpenEUICC

因为它是系统应用，不像普通 APK 能签名分发。维护者只发 CI debug 构建，正式集成方式是让 ROM 开发者在编译 AOSP 时把整个项目作为 PRODUCT_PACKAGES 加进去。普通用户走 Magisk 模块路线即可。

国内怎么 0 成本开 giffgaff eSIM？giffgaff

用电脑里的安卓模拟器（MuMu）+ Magisk + LSPosed + HookEuicc，让 giffgaff App 误以为设备支持 eSIM，在 App 内购买拿到激活码，再装到支持 eSIM 的设备 / 转接卡 / 9esim 下发方案上。模拟器只是开卡工具，不是最终使用设备。完整步骤见上方 giffgaff 章节。

国行 iPhone 能用 giffgaff eSIM 吗？giffgaff

国行 iPhone 不支持原生添加 eSIM。但可以先用模拟器开出激活码，再通过 eSIM 转接卡（5ber、esim.me、eSTK.me 等）或 9esim 下发方案使用。
