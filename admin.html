页面浏览量、设备大类和平均停留等汇总计数需要一个数据库。按下面三步连接 Upstash Redis：

  1. 打开 Vercel 项目 → Storage 标签 → Create Database → 选 Upstash for Redis（免费档够用）。
  2. 创建后点 Connect Project 连到本项目，Vercel 会自动注入 KV_REST_API_URL / KV_REST_API_TOKEN（或 UPSTASH_REDIS_REST_URL / UPSTASH_REDIS_REST_TOKEN）。
  3. 到 Deployments 里 Redeploy 一次，刷新本页即可开始记录。
